# COEIROINK v2 API bridge

VOICEVOX のAPIで COEIROINK v2 を操作するためのブリッジ。
sevenc-nanashiさんの[coeiroink-v2-bridge](https://github.com/sevenc-nanashi/coeiroink-v2-bridge)のフォークです

> [!WARNING]
> このブリッジの初回起動時は、COEIROINK v2 が起動している必要があります。
> 2回目以降は、COEIROINK v2 が起動していなくても自動で起動します。
>
> Home AssistantでCOEIROINKを使うためのものです
> Home Assistant以外では動作確認していません。

## 使い方
### ビルド済みバイナリ
準備中

### deno
```
deno task start
```
